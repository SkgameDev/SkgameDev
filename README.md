### How I build

Every game follows the same path, and I own all of it:

```
concept  →  prototype  →  core loop  →  content & levels  →  art & audio pass
       →  performance pass  →  device testing  →  ad integration
       →  store listing & ASO  →  closed test  →  production release  →  updates
```

I automate the repetitive parts — build scripts, automated self-tests that play through
every level, device test harnesses — so the time goes into the game instead of the process.
